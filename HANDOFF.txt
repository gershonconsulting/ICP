WHAT IT IS
- The GPT USA 12-point analysis as a web app. Input: company URL (+ optional name, notes). Output: 12 sections, saved reports list,
  "Copy as prospect email" (subject "Customized GPT USA by Gershon Consulting for <Company>" + Aina's standard intro).
- Modeled on events.gershon.ai. AI = Cloudflare Workers AI (@cf/meta/llama-3.3-70b-instruct-fp8-fast) — no Anthropic/OpenAI keys
  (Olivier's "Intelligence" standard). Do NOT use the Fable model anywhere (Olivier's instruction).
- Meteor Biotech report is seeded on first sign-in (src/seed.json).

HOW IT DEPLOYS (no tokens, no GitHub secrets)
- Cloudflare Workers Builds is connected to this repo (Worker "icp-gershon-ai", account oattia@gmail.com, branch main,
  deploy command "npx wrangler deploy"). KV "icp-gershon-ai-store" (4bf369dab5d8439a959f5af7b7ed7d95) was auto-provisioned.
- Cloudflare shows the GitHub connection as "disconnected", so pushes do not auto-trigger. After each push, POST the
  Deploy Hook "claude-deploy" (main): Cloudflare → icp-gershon-ai → Settings → Builds → Deploy Hooks.
- GitHub Actions (.github/workflows/tests.yml) runs the unit tests on every push.
